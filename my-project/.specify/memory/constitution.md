# Content Calendar & Audit Engine Constitution

## Core Principles

### I. 10-Field Mandatory Content Calendar Metadata Schema
Every content calendar item generated or processed from a website or post repository MUST adhere strictly to the 10-field metadata schema:
1. `Publish Date`: Scheduled publication date in YYYY-MM-DD format.
2. `Blog Title`: Proposed headline or existing published blog title.
3. `Primary Keyword`: Main search keyword target for the post.
4. `Secondary Keyword`: Comma-separated list of supporting keywords.
5. `Search Intent`: Categorized search intent (`Informational`, `Commercial`, `Transactional`, `Navigational`).
6. `Target Audience`: Specific user persona or demographic targeted by the content.
7. `Content Type`: Content format classification (e.g., `Blog Post`, `Trekking Itinerary`, `Guide`, `Comparison`, `FAQ Article`).
8. `Link to Blog`: Canonical URL for existing blogs or planned slug path for upcoming posts.
9. `CTA`: Actionable Call-To-Action instruction or conversion goal.
10. `Priority`: Strict priority level enum (`High`, `Medium`, `Low`).

Incomplete content entries MUST be flagged for schema validation errors and shall not be published to production calendars until all 10 fields are fully populated.

### II. Automated Content Audit & Gap Intelligence
When analyzing a target domain or existing post repository, the engine MUST execute automated content auditing to identify and categorize:
- **Content Gaps**: Unaddressed high-volume or high-intent search topics missing from the site's coverage.
- **Outdated Blogs**: Existing articles needing content refreshes, updated statistics, year updates, or SEO optimizations.
- **Seasonal Opportunities**: Time-sensitive trekking/travel trips and seasonal topic triggers requiring scheduling ahead of peak interest.
- **FAQ Opportunities**: Common user questions and search queries suitable for dedicated FAQ sections or structured data schema.

All audit results MUST directly feed into content calendar recommendations with clear rationale.

### III. Intent-Driven Priority & Scheduling Logic
Priority assignment (`High`, `Medium`, `Low`) and scheduling dates (`Publish Date`) MUST be calculated deterministically using the following rules:
- **High Priority**: Immediate content gaps in high-converting commercial/transactional intent topics, severely outdated top-performing blogs needing updates, and seasonal trekking trips scheduled 60-90 days prior to peak season.
- **Medium Priority**: Informational topics filling secondary content gaps, moderately outdated blogs, and standard FAQs.
- **Low Priority**: General evergreen background content, minor copy refinements, or long-tail informational queries.

Prioritization MUST NOT be assigned arbitrarily without clear intent and impact metrics.

### IV. Non-Destructive Data Ingestion & Source Traceability
When ingesting existing websites or content databases:
- All live URLs and blog links (`Link to Blog`) MUST be mapped without loss or alteration.
- Every audit finding or suggested calendar item MUST maintain explicit lineage back to its source URL (for updates) or identified content gap (for new content).
- Re-running an audit or calendar generation on an existing website MUST NOT overwrite custom user modifications without explicit confirmation and version tracking.

### V. High-Quality SEO & Reader-Centric Content Standards
All titles, keywords, search intents, CTAs, and FAQs generated by the system MUST maintain reader-centric readability, avoiding keyword stuffing or unnatural phrasing. Content strategies MUST adhere to search engine quality guidelines (Experience, Expertise, Authoritativeness, and Trustworthiness - EEAT).

## Technical & Data Specifications

The engine MUST support structured data export and import formats including JSON, CSV, and Google Sheets compatibility. Data pipelines MUST implement robust web scraping, URL extraction, and page parsing components with rate-limiting and error handling for remote website ingestion.

Audit components MUST maintain isolated modules for Content Gap Analysis, Outdated Blog Identification, Seasonal Trip Tracking, and FAQ Extraction to ensure modular testability and independent enhancement.

## Quality & Audit Workflow

1. **Schema Validation Gate**: Every generated calendar item MUST pass strict validation against the 10-field schema before presentation or export.
2. **Audit Accuracy Gate**: Audit recommendations (Outdated, Gap, Seasonal, FAQ) MUST include actionable metrics and clear rationale.
3. **Automated Testing**: Test suites MUST validate metadata parsing, priority determination logic, seasonal lead-time calculations, and URL mapping.
